# RetroSpec CLI — submissions

This is where corrections and additions to the [RetroSpec CLI](https://retrospec-cli.com)
dataset come in. There's no code here, just issues.

## Submitting something

Easiest way is from the site: find the option on the
[wiki](https://retrospec-cli.com/wiki), hit **+ add data**, and it'll open an issue with
everything filled in.

You can also just open one yourself. What we need either way:

- which car — generation, body style, model year
- the option code and name
- the price, as printed
- **where it came from** — a link, or the document and its date

That last one isn't optional. Every price in the dataset carries its source so anyone can
check it, and we can't take a figure we can't trace.

## What happens next

Everything gets reviewed before it goes in. Sourced entries land in the ledger with your
citation attached; if you gave a name, that's how you'll be credited.

## Licensing

The dataset is open under [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) and
DbCL 1.0. Submitting means you're happy for your contribution to go in under those, that it
isn't copied out of brochure text or someone else's photographs, and that you're not
guessing at the numbers. Full details in
[CONTRIBUTING.md](https://retrospec-cli.com/data-license).

The site's own source code is not open, and this repo doesn't accept code.
